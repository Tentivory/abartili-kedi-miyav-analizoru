# Abartılı Kedi Miyav Analizörü

## Giriş

Bu proje, insanlığın en büyük sorularından birine cevap arar: Kediler neden miyavlar? Ve bu miyavlar, aslında evrenin derinliklerinden gelen felsefi mesajlar mıdır?

**Evet.** Ve biz bunu abartılı bir ciddiyetle analiz ediyoruz.

Bu analizör, her miyavı 47 katmanlı bir bilimsel protokolden geçirir. Her katman, bir öncekini bekler. Sonsuza kadar. Ama sonunda bir şey söyler. Belki.

## Kurulum

```bash
pip install -r requirements.txt  # Aslında hiçbir şey yok, ama olsun
python miyav_analiz.py
```

## Kullanım

Programı çalıştırın. Bir miyav girin. Veya sadece enter'a basın. Analiz başlar. Bekleyin. Ciddiyetle bekleyin.

## Özellikler

- %99.7 doğruluk oranı (geri kalan %0.3 kedi tarafından onaylanmamıştır)
- Sonsuz bekleme modu
- Felsefi derinlik seviyesi: 11/10
- Gizli katmanlar (açıklanmaz)

## Lisans

MIT ama aslında hiçbir şey lisanslı değil. Miyavlar serbesttir.
